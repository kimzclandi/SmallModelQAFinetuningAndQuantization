# 新文段留出集上的教师一致性门控蒸馏

本研究只检验一个新假设：在 TRAIN 中，教师 top-1 token 与 gold 一致的位置才施加 KL，能否让学生在新的项目留出文段上超过同条件 gold-SFT。方法由已观察的 TRAIN 统计及历史 dev 负结果提出，不能把它称为全新原创算法，也不能把本研究的结果用于追认历史 dev 的独立性。

运行前冻结的完整约束见 [protocol.json](../configs/teacher-gated-confirmation-v1/protocol.json)。本页在执行前建立；结果将在新的报告目录中保存，历史 v1、v2、失败记录和模型保持原样。

## 为什么需要重跑控制组

历史 v2 的 dev EM 为 60.36%±2.81%，低于历史 gold242 的 64.86%±1.35%。虽然训练 ID、步数和 LoRA 超参数匹配，但旧 full-KD 在 CPU、旧 gold242 在 MPS；计时范围也不同。新的三臂全部通过同一 CPU/FP32/eager 训练循环，三个 seed 各 242 步，初始 LoRA 状态与训练 ID 顺序另存哈希，避免把旧组当成设备一致的新控制组。

| 组 | 固定目标 |
|---|---|
| gold | 答案 token 上的 CE，权重 1 |
| full_kd | 0.5 CE + 0.5 T² KL，T=2 |
| gated_kd | 同上，但只保留教师 argmax=gold 的 KL 项；分母仍为所有监督 token 数 N |

旧 TRAIN 诊断中，1,289 个监督位置有 1,141 个一致、148 个不一致。门控同时改变位置选择与有效 KL 总量；没有均匀降低 KL 的第四组，因此结果不能单独证明教师不一致是失败根因，也不能把标量 loss 占比写成梯度主导。

## 数据独立性的范围

数据来自本地已有的 SQuAD 2.0 官方公开 dev 文件。三个项目已有数据涉及全部 35 篇文章，因此没有“全新文章”可以声称。本研究只从未出现在审计到的项目实验输入中的文段抽取，排除既有 QA ID、归一化文段、相同及近重复问题；检索许可信息时意外显示过摘要的五篇文章整篇排除。

选择固定 128 个文段，每文段一条可回答、一条不可回答，共 256 题；按固定 hash 顺序跨文章轮转。失败、超长输入、格式错误不会被替换为更容易的样本。不能把它称为官方隐藏测试、文章级泛化、业务流量或预训练无污染。

输入与标签分文件保存。先训练并锁定九个 adapter，预测进程只读取无标签输入；九份预测全部完成并保存哈希后，评分阶段才解析标签。这是可审计的执行流程，不是对抗式加密盲法。首次结果产生后，该留出集已被消耗，后续依据它改方法只能算开发。

## 判断与预算

主比较始终为 gated_kd − gold。接受需同时满足：三个 seed 平均 EM 提升至少 3 个百分点；文章聚类的配对 bootstrap 95% 区间下界大于零；至少两个 seed 改善；可回答/不可回答两类的平均 EM 均不下降超过 2 个百分点；每个候选 seed 的格式有效率至少 99%。完整 KL 组是次要对照，不能在主比较失败后替代主比较。

EM/F1 沿用本项目的 SQuAD-style 归一化实现，拒答必须为 `NO_ANSWER`；另报原文片段格式有效率。它不是官方 SQuAD scorer 的榜单成绩。bootstrap 先对同题三个 seed 取平均，再按文章有放回抽样，保留文章内全部样本、按题加权；它不覆盖全部训练 seed 不确定性。

只使用现有 0.5B 学生、1.5B 教师的固定本地快照，逐文件核验权重、配置及 tokenizer。重新生成有模型字节身份的新 TRAIN cache，旧 cache 不被补签或覆盖。总预算 90 分钟、输出 8 GiB、采样 RSS 24 GiB，单训练/推理进程上限 15 分钟。无下载、付费 API、GPU 申请或权重公开上传。所有成本记录仅用于资源说明，不形成推理加速倍率。

## 执行入口

安装环境沿用仓库锁定依赖；命令从仓库根目录运行。下面的两个本地路径由执行者提供，不是下载入口。代码与协议必须先提交，工作区追踪文件必须干净。

```bash
python scripts/prepare_confirmation_data.py \
  --source /local/path/squad-dev-v2.0.json \
  --output work/teacher-gated-cohort-v1
HF_HUB_OFFLINE=1 python -m qa_lab.confirmation_study run \
  --cohort work/teacher-gated-cohort-v1 \
  --cache-dir /local/path/huggingface/hub \
  --output work/teacher-gated-confirmation-v1
```

输入、协议、模型或缓存 hash 不符，非有限 loss/梯度，计时/内存/磁盘超限，输入超长或覆盖不足时即停止，保留已完成步骤与失败记录。不得覆盖结果、调门槛或挑一个 seed。执行故障的重启需要新的明确版本及原因；已观察评分不能用于继续调参并称独立确认。

## 贡献与证据边界

本轮是维护者授权、AI 辅助完成的实验实现与验收；Qwen、PyTorch、Transformers、PEFT 和已有 KL/LoRA 方法归属上游。公开文件中的代码、配置、逐题预测、loss 记录及哈希可用于审查实现与算术；离线 CI 不重新加载模型，不能独立证明所有训练/推理输出。三个组的学生规模相同，本研究首先回答 soft targets 是否有质量收益，不同时证明量化、教师质量保持、推理加速或生产部署。
