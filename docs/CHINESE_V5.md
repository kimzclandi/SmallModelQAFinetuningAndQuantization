# 第五轮：冻结Q8候选的中文新来源验证

## 输入、输出与假设

输入来自官方CMRC2018公开dev，固定版本c0eb1b6ba219847457e6af3180da722bbeb656af。先用固定hash顺序抽96题，每篇文章最多一题，核对原文答案offset、输入token上限2048，并排除与旧项目数据及本子集的近重复。输出是FP16与已经在第四轮选中的Q8各96条预测、逐题评分、修复/回归与冻结门槛结果。

两份模型权重与第四轮完全相同，没有中文训练、LoRA合并、重新量化或教师标签。中文系统提示在推理前固定，两模型完全共用。这里检验的是已选压缩方案在新语言/数据来源下的质量保持，而不是训练算法或中文提示词改写的收益。

数据属于通用中文抽取式阅读理解，不是企业业务问答。本子集全部有答案，不能检验信息不足时是否编造。虽未用于本项目调参，仍是公开benchmark，不能保证模型预训练未见。

## 不能直接搬用英文指标

英文评测的空格token切分不适合连续汉字。本轮主指标是**strict EM**：只去掉预测/参考答案首尾空白，与任一参考字符串完全相同才得1分。96题等权，任何空输出、截断、拒答仍留在分母中。

补充报告两个自定义指标，明确**不是CMRC官方榜单实现或分数**：

- normalized EM：Unicode NFC、casefold、移除Unicode标点与空白后完全匹配。
- character LCS F1：对上述归一化后的字符序列计算最长公共子序列长度L，得分为2L/(预测长度+参考长度)，多参考取最高分。顺序不同会受罚，不是字符袋重叠。

例如“甲乙”和“乙甲”的LCS只有1个字符，F1为0.5。归一化也有风险：“3.14”和“314”会在去标点后相同，因此严格EM是主指标，原文片段格式另行检查，不能只展示归一化分数。

判断相对FP16的质量保持：严格EM最多下降1/96、字符LCS F1最多下降2个百分点、格式有效率最多下降1/96。此门槛在任何本轮推理前提交，不依结果修改。它不是显著性检验，也不是业务验收标准。

## 隔离与许可

使用CC BY-SA4.0数据，完整原始许可证及作者归属在data/chinese-v5。项目只提交96题许可子集，不提交3.3MB完整原文件。原文件下载URL、版本和SHA256在configs/chinese-v5/protocol.json与data manifest里。未调用付费API，也未将新的评测反馈用于训练。

候选来自第四轮而非本轮分数；数据、模型文件hash和代码先提交，再运行FP16/Q8各一次。旧数据文本只用于近重复排除，没有旧test模型推理。文件format字段和根因推断分开：看到非原文输出能确认格式问题，不能仅凭一条错误就断言“模型不懂中文”或“缺知识”。

## 复现与核验

旧输出不可覆盖。离线核验可以在只有标准库的环境运行：

```bash
PYTHONPATH=. .venv/bin/python scripts/verify_chinese.py
```

核验不会下载数据、加载模型或再次推理。原运行入口与命令保存在scripts/chinese_study.py和reports/chinese-v5/commands.jsonl；读取完整数据时用固定SHA256核对，不默认拉最新版本。

若需实际小规模复现，请先按docs/QUANTIZATION_V4.md建立同版本FP16/Q8模型，再使用新的隔离输出目录：

```bash
PYTHONPATH=. HF_HUB_OFFLINE=1 .venv-mlx/bin/python scripts/chinese_study.py reproduce \
  --variant q8 --model .cache/mlx/student-q8 \
  --output work/chinese-reproduction-01 --limit 2
```

去掉`--limit 2`会在新目录复现全部96题，请不要反复将结果用于选择新模型。`reproduce`只允许转换时间戳/模型卡/许可证文件与原冻结集不同，数值权重、模型配置和tokenizer文件必须匹配；所有实际文件hash仍写入新run.json。重新转换若产生不同权重或配置，会明确拒绝，不能冒充原模型的复现。已有输出一律拒绝覆盖。

原`infer`入口服务冻结实验，继续要求原始文件集全部匹配；不要为了复现而修改历史model-freeze。
