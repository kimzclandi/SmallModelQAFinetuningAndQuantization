本次维护发生在既有实验之后，没有新增训练或模型质量结论。

发现：数据构建器拒绝重复教师 ID，但训练入口将教师预测直接转为字典，重复行被静默合并。一个包含重复行且文件哈希一致的教师记录会通过训练入口的覆盖检查。
修复：训练前同时检查原始预测条数、唯一 ID 数量和训练样本 ID 集合；不删除重复行、不自动修正教师输出。
