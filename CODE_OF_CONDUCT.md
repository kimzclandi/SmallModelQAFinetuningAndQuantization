# Community conduct / 社区行为准则

Discuss technical ideas with respect. Explain disagreements using reproducible examples,
listen to corrections, and give credit to contributors and upstream work. Chinese and
English contributions are welcome. Harassment, threats, discrimination, personal attacks,
and publishing another person's private information are not acceptable.

These expectations apply to this repository's issues, pull requests and other spaces
managed by its maintainers. Maintainers may edit or remove harmful content, lock a
conversation, or restrict participation, with an explanation when appropriate.

For public technical disagreements, request maintainer review in the existing discussion.
Do not post sensitive details or personal information in a public issue. Use GitHub's
[Report abuse](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam)
channel for harassment or private safety reports. This project does not currently advertise
a dedicated confidential conduct-reporting inbox or a response-time guarantee.
